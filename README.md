# 问名 · 青囊起名

用八字五行、生肖冲合、康熙五格和音韵羽翼，给新生儿或品牌取一组可解释的名字。

打开页面后选「新生儿」或「品牌」。新生儿填姓氏、性别和公历生日，时辰不知道可以空着。品牌选行业，也可以附上创始人生辰。点「起名」之后，左边是四柱和喜用，右边是八个名字；点开一个名字，能看到每个字的五行、笔画、五格和为什么这样配。

## 本地运行

```bash
npm install
npm run dev
```

浏览器打开 [http://127.0.0.1:38471](http://127.0.0.1:38471)。

```bash
npm test
```

测试覆盖三个排盘锚点：2000-01-01 午时为己卯、丙子、戊午、戊午；1985-03-12 酉时为乙丑、己卯、庚戌、乙酉；2024-02-06 年柱已过立春为甲辰，春节生肖仍是兔。

## 计算口径

- 八字用节气交节，不按农历初一换月。晚子时（23:00 后）日柱进到下一天。
- 身旺身弱按月令、藏干和生克力量估算。喜用只补对日主有益的五行；盘里缺少的元素若是忌神，不会硬补。
- 生肖按春节，年柱按立春。二者不一致时会同时写明。相冲字根不进名字。
- 五格用康熙部首还原笔画：氵按水、艹按艸、王旁按玉，简体字按对应繁体计。超过 81 的数理减 80 再查。人格、地格、总格若落在 34、44、54、64，名字会被丢掉。
- 羽翼指双名的分工：一个字承德行，一个字负责气象；字形错开，声母不要撞在一起。
- 品牌名另看行业五行、好不好念、能不能被记住。这不是商标法律意见。

这是一套文化计算，用来取舍名字，不是命运判决。字库三百七十余字，其中一百二十余字标了《诗经》《论语》《楚辞》等出处。冷僻姓如果没有笔画，页面会请你补上康熙画数。

## 手机、电脑、网页

同一个页面，三种打开方式：

- 网页和电脑浏览器：[https://liushunhao.github.io/name_aura/](https://liushunhao.github.io/name_aura/)
- 手机：用浏览器打开上面的网址。iPhone 在分享里选「添加到主屏幕」，安卓在浏览器菜单里选「安装应用」或「添加到主屏幕」。之后从图标打开，不必再输地址。
- Windows 电脑也可以双击仓库根目录的 `wenming.exe`。它会留下一个命令行窗口，并在浏览器打开 http://127.0.0.1:38471 。关掉那个窗口，程序就退出。不需要安装 Node。

重新打包：

```bash
sh scripts/build_exe.sh
```

产物在 `desktop/青囊起名.exe`，发布到仓库时复制为根目录的 `wenming.exe`。
